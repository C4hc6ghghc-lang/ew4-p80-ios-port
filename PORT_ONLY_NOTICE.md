# PORT_ONLY distribution note

This package intentionally excludes the original EW4 APK binary.

Included: the reconstructed Web/PWA port source, runtime assets used by the port, tests, audits, handoff notes, and final verification records.

Excluded: the original APK binary itself and its standalone ORIGINAL_APK folder.

Historical audit files may still mention the original APK filename or SHA-256 as provenance/evidence. Those references are text metadata only and do not mean the APK is embedded in this ZIP.
